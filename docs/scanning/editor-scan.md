# Scanning in the editor

A11yScanFix checks a single post or page right where you write it, so problems
are caught before you publish.

## Block Editor sidebar

When editing a post or page, open the A11yScanFix panel in the editor sidebar.
It lists the accessibility issues found on that content, grouped by rule, with
the impact level and a short explanation of how to fix each one.

## Front-end highlighter

From the admin bar on any front-end page, open the A11yScanFix highlighter to
see issues marked directly on the rendered page.

## Scan on save / publish <span class="pro">PRO</span>

!!! note "PRO feature"
    In Pro, content is re-checked automatically when you Save or Publish, so
    the sidebar stays current without a manual scan.
