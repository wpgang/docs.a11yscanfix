# What's in Pro

A11yScanFix Pro is an add-on that installs alongside Free and unlocks the
heavy-lifting features. Everything in Free stays included.

## Pro adds

- **Scan custom post types, archives and taxonomies** (incl. WooCommerce). See
  [CPT, archives and taxonomies](../scanning/archives-cpt.md).
- **5 advanced fixers** - form labels, heading order, ARIA landmarks, duplicate
  IDs, empty links. See [Advanced fixers](../fixers/pro-fixers.md).
- **Dismiss issues with audit log**. See [Dismiss issues](../dashboard/dismiss-issues.md).
- **Scan speed** - Default / Fast / Faster / Experimental.
- **Scheduled email report** - Weekly / Monthly. See [Scheduled report](../dashboard/scheduled-report.md).
- **Trend chart + CSV / JSON export**. See [Trend and export](../dashboard/trend-and-export.md).
- **Role-based permissions**.
- **In-editor auto-check on Save / Publish**.
- **Email support**.
