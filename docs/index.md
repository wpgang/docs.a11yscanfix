# A11yScanFix Documentation

A11yScanFix is one WordPress plugin that does three jobs: **scan** your site
for WCAG issues, **fix** the common ones automatically, and generate **AI alt
text** for your images. Real code fixes, not an overlay.

This site documents both the **Free** and the **Pro** add-on. Pro-only
features are marked with a <span class="pro">PRO</span> badge.

## The three jobs

- **Scan** - 40+ WCAG 2.2 AA checks in the editor and across the whole site,
  powered by axe-core, running entirely in your browser.
- **Fix** - 13 automated fixers in Free, plus 5 advanced fixers in Pro. Toggle
  on, fully reversible, no theme edits.
- **Alt text** - AI-generated alt text on upload, using your own API key
  (OpenAI, Claude, Gemini, or Mistral). No per-image fees, no data sent to us.

## Free vs Pro at a glance

| Area | Free | Pro |
| --- | --- | --- |
| Full-site scan (posts + pages) | Yes | Yes |
| Scan CPT / archives / WooCommerce | - | Yes |
| Automated fixers | 13 | 13 + 5 advanced |
| AI alt text (your own key) | Yes | Yes |
| Dismiss issues + audit log | - | Yes |
| Trend chart + CSV / JSON export | - | Yes |
| Scheduled email report | - | Yes |
| Scan speed (Default / Fast / Faster / Experimental) | Default | All |
