# Bulk generate alt text

Fill alt text for images already in your Media Library in one pass.

## How to run it

1. Go to **A11yScanFix -> AI Alt Text**.
2. Click **Find images without alt text** to build the list.
3. Click **Generate alt text** to start.
4. A progress bar shows "Generating X of N", with succeeded and failed counts.
   You can **Cancel** at any time.

## Notes

- Only images that are missing alt text are processed, so re-running is safe.
- Generation uses your own API key, so cost depends on your provider's pricing.
- Large libraries can take a while; keep the tab open while it runs.
