# AI alt text

A11yScanFix can write descriptive alt text for your images using AI. You bring
your own API key, so there are no per-image fees and no vendor lock-in. Image
data goes straight from your site to the provider you chose - never to us.

## Two ways to use it

- **On upload** - turn on auto-generate, and every newly uploaded image gets
  alt text automatically.
- **In bulk** - fill alt text for images already in your Media Library. See
  [Bulk generate](bulk-generate.md).

## Setup in short

1. Go to **A11yScanFix -> AI Alt Text**.
2. Pick a provider and paste your API key.
3. Choose the model.
4. Optionally enable **Auto-generate on upload**.

See [Providers and keys](providers-and-keys.md) for details.
