# Advanced fixers (5) <span class="pro">PRO</span>

!!! note "PRO feature"
    These five harder fixes are part of the A11yScanFix Pro add-on. With Free's
    13, that is 18 fixers in total.

| Fixer | What it does |
| --- | --- |
| Form labels | Adds programmatic labels to form fields that are missing them. |
| Heading order | Corrects skipped or out-of-order heading levels. |
| ARIA landmarks | Adds missing landmark roles so assistive tech can navigate regions. |
| Duplicate IDs | Resolves repeated `id` values that break references and labels. |
| Empty links | Gives an accessible name to links that have no text. |
