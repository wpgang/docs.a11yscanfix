# Free fixers (13)

All thirteen are included in A11yScanFix Free.

| Fixer | What it does |
| --- | --- |
| Skip links | Adds a "Skip to content" link as the first focusable element. |
| Focus outlines | Restores a visible keyboard focus ring on interactive elements. |
| HTML lang | Ensures the page has a valid `lang` attribute. |
| Search form label | Adds an accessible label to the WordPress search form. |
| Results on empty search | Returns a usable results page instead of a dead end on empty search. |
| Remove positive tabindex | Removes `tabindex` values above 0 that break focus order. |
| Remove redundant title | Strips `title` attributes that just duplicate visible text. |
| Make viewport scalable | Removes `maximum-scale` / `user-scalable=no` so users can zoom. |
| Label new-window links | Warns users when a link opens in a new tab. |
| Label document links | Flags links to documents (PDF and similar). |
| Underline content links | Underlines in-content links so they are distinguishable. |
| Comment form labels | Adds accessible labels to the comment form fields. |
| Autoplay video controls | Ensures autoplaying video exposes controls. |
