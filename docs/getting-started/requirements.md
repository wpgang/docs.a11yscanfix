# Requirements

| Requirement | Minimum |
| --- | --- |
| WordPress | 6.4 or newer |
| PHP | 8.0 or newer |
| Browser (for scanning) | Any current Chrome, Edge, Firefox, Safari, Brave, Opera |

## How scanning works

The scanner runs **in your browser** using axe-core - the same engine behind
Lighthouse and the Deque tools. Nothing about your pages is sent to A11yScanFix
or any third party. Results are saved to your own database.

Because the scan runs in the browser tab, keep the dashboard tab open while a
full-site scan is in progress. You can pause and resume long scans.
