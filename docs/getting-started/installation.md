# Installation

## A11yScanFix Free

!!! warning "✏️ FILL IN: where Free is distributed"
    Is Free published on WordPress.org yet? The steps below assume it is. If it
    is still pre-launch, replace with the manual zip upload steps and the early
    access link.
    <!--FILLIN-->

1. In your WordPress admin, go to **Plugins -> Add New**.
2. Search for **A11yScanFix**.
3. Click **Install Now**, then **Activate**.
4. A new **A11yScanFix** menu item appears in the admin sidebar.

Manual install (zip):

1. Download the plugin zip.
2. Go to **Plugins -> Add New -> Upload Plugin**.
3. Choose the zip, click **Install Now**, then **Activate**.

## A11yScanFix Pro

Pro is a separate add-on installed alongside Free. Keep Free active.

!!! warning "✏️ FILL IN: Pro delivery + license"
    How is Pro delivered (Freemius / direct zip / account download)? What does
    the user enter to activate the license, and where? Add the exact steps and
    the account / checkout URL.
    <!--FILLIN-->

1. Install and activate **A11yScanFix Free** first.
2. Upload and activate the **A11yScanFix Pro** add-on (Plugins -> Add New ->
   Upload Plugin).
3. Enter your license key under **A11yScanFix -> Settings**.
4. Pro features unlock immediately.
